Política de Privacidade

Esta é uma vitrine estática publicada no GitHub Pages. Nesta versão, não há cadastro, login, pagamento ou envio de formulários para um servidor. As informações digitadas nos formulários não são transmitidas por esta página.

Os itens do carrinho são mantidos apenas no armazenamento local do navegador para permitir a demonstração da navegação. Limpar os dados do navegador remove esses itens.

Links para serviços externos, como lojas de aplicativos, seguem as políticas de privacidade dos respectivos serviços.
